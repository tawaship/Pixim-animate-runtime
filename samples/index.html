Each sample is content published from Adobe Animate (<sample>/<name>.html and .js) and the runtime content generated from it with npx --no-install @tawaship/pixi-animate-runtime <sample> (<sample>/generated/). pixim-animate-runtime plays it as a Pixim application does: the content is defined with defineAnimateContentsTo (its runtime content file as filepath) and played by an AnimateContainer. Switch the player to compare the two: only one plays at a time, so the frame rate shown is that player's alone. Choosing a symbol plays it as the root, created without arguments.
