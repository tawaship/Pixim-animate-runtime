    create

    • create(id: string): DisplayObject

      An instance of a symbol for the application to place, set up as the HTML template sets up the root it creates: a clip that re-caches its children's color effects (it has a filterCacheList) gets the filter cache handling, which published code otherwise gets from the symbol that creates it (an instance made by new lib[id]() in a frame script gets none, as in CreateJS). The handling does not change what the player draws (it draws color effects without caches); it keeps the instance's state the template's.
