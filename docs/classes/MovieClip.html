    Class MovieClip

    createjs-compatible MovieClip. Plays its symbol's timeline from the shared definition with createjs's rules: the two phases (tick: advance the playhead; then resolve: write the tweens and settle the children), the write rule (a tween writes only when its position changes), synched / single children taking their frame from the parent's step, the reset of an independent child when it comes back on the display list, and when frame scripts run.
