    Class AnimateContentLoader

    Loads a content as a Pixim asset: its runtime content file (when a filepath is given), then the content with loadContentAsync, the base path being the Pixim content's and the target's together.

    With the Pixim content's xhr option, the images are fetched (with its request options) into blob: URLs first, after the target's own handleManifest; the blob: URLs are released once the content is loaded.
